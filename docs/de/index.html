Ein Urteil.

review-pro prüft KI-geschriebenen Code in Stufen. Das Triage leitet nur die relevanten Spezialisten weiter, jeder läuft in seinem eigenen Geltungsbereich, dann gibt die Synthese ein Urteil zurück. Gebaut für die Fehlermuster, die KI-Code tatsächlich ausliefert.

01STUFE

Triage

Klassifiziere den Diff und leite nur die Spezialisten weiter, die für diese Änderung wichtig sind. Jeder erhält einen Geltungsbereich — Aufrufer, Repo-Suche, Schema, Konsumenten — nicht das gesamte Repository.

klassifiziereneingrenzenweiterleiten
02STUFE

Verteilung

Die relevanten Spezialisten laufen parallel. Zwölf Prüfer, jeder besitzt ein Anliegen, jeder liefert strukturierte, belegte Befunde mit Datei, Zeile, Auswirkung und Abhilfe.

paralleleingegrenztstrukturiert
03STUFE

Synthese

Dedupliziere Überschneidungen, löse Konflikte zwischen Prüfern nach Fachverantwortung, kalibriere den Schweregrad gegen Übermeldungen und gib ein Urteil heraus — BLOCK, REQUEST CHANGES oder APPROVE.

deduplizierenauflösenUrteil

Funktionen

Eine Prüfbank, nicht eine große Vermutung.

Jeder Spezialist besitzt ein einziges Anliegen und eine strenge Rubrik. Eine erstklassige KI-Anti-Pattern-Linse erfasst, was generische Prüfer übersehen — halluzinierte APIs, Über-Engineering, ignorierte Helfer, überflüssige Abhängigkeiten.

Installation

Ein Befehl. Kein Lock-in.

Installiere den Kern in dein Tool und füge dann die Stack-Pakete hinzu, die du nutzt.

npx review-pro init            # interactive: pick platforms + stacks
npx review-pro add python      # add a stack to .review-pro/

Kein Node.js? review-pro besteht aus reinen Markdown-Skills und -Agenten — kopiere sie in den Ordner deines Tools und es funktioniert genauso. Siehe die Anleitung zur manuellen Installation.

Starte dann dein Tool neu und führe eine Prüfung aus — öffne einen Branch und bitte die Session, ihn zu prüfen, oder rufe den review-pro-Skill auf.
