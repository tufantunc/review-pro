Overzicht

review-pro is een gelaagd AI-code-reviewsysteem: triage → relevante specialistische reviewers → synthese. Het beoordeelt code die door AI-agents is geschreven met behulp van AI-agents — gebouwd om de foutpatronen te vangen die AI-gegenereerde code werkelijk meebrengt: gehallucineerde API's, over-engineering, genegeerde conventies, overbodige afhankelijkheden.

Deze CLI installeert de review-pro-kern (12 reviewer-skills + subagents + de review-pro-orchestrator) in je agent-tool, en de stack-pakketten in de .review-pro/ van je repo. Ondersteunde doelen: opencode · Claude Code · Cursor · Codex.

Installatie

Eenmalig. Interactief — het vraagt welke platformen en welke stack-pakketten te installeren.

npx review-pro init                           # interactive: pick platforms + stacks

Niet-interactief (CI)? Gebruik --target <platform|all|auto> en --no-stacks.

Notities per platform

  • opencode — skills naar ~/.config/opencode/skills/, agents naar ~/.config/opencode/agents/ ($OPENCODE_HOME overschrijft).
  • Claude Code — skills naar ~/.claude/skills/, agents naar ~/.claude/agents/ (het skills:-veld van de agent preloadt zijn rubriek).
  • Cursor — geïnstalleerd via Cursor /add-plugin; voer /add-plugin https://github.com/tufantunc/review-pro uit in Cursor (de repo levert een .cursor-plugin/plugin.json).
  • Codex — skills naar ~/.agents/skills/, agents automatisch getransformeerd naar ~/.codex/agents/*.toml. Codex ontdekt skills automatisch; agents erven de skill-set van de sessie.

Voeg daarna de stack-pakketten toe die je gebruikt (hieronder), herstart je tool zodat de nieuwe skills/agents worden ontdekt, en voer een review uit.

Handmatige installatie (zonder Node.js)

review-pro bestaat uit gewone markdown-skills en -agents — geen runtime-afhankelijkheid. Als je geen Node.js hebt (of de CLI niet wilt gebruiken), kopieer de bestanden handmatig:

  1. Kern — kopieer core/skills/<name>/ naar de skills-map van je tool en core/agents/*.md naar diens agents-map (paden zoals hierboven per platform).
  2. Stack-pakketten — kopieer stacks/<pack>/ naar de .review-pro/<pack>/ van de beoordeelde repo.
# example: opencode core + python stack, by hand
cp -R core/skills/*           ~/.config/opencode/skills/
cp    core/agents/*.md        ~/.config/opencode/agents/
mkdir -p .review-pro && cp -R stacks/python .review-pro/python

De CLI automatiseert alleen deze kopieën (plus de Codex .md→.toml-transformatie en versie-tracking). Handmatige en CLI-installaties zijn equivalent.

Stack-pakketten

Pakketten schakelen taal-/framework-specifieke signalen op de reviewers tijdens de review. Installeer de pakketten die een repo gebruikt in diens .review-pro/. Framework-/domein-pakketten combineren bovenop een taalpakket.

npx review-pro                # interactive multi-select
npx review-pro add python     # one pack, CI-safe
npx review-pro list           # catalog + installed + drift

Catalogus (14): python · go · rust · typescript-react · node · php · dotnet · kotlin · swift · flutter · nextjs · react-native · wordpress · ai-ml. Voorbeelden: een Next.js-repo activeert typescript-react + nextjs; een LLM-app activeert python + ai-ml.

Review uitvoeren

Na installatie + herstart, in de repo die je wilt beoordelen (op een feature-branch):

  • vraag de sessie om deze branch te beoordelen met review-pro, of
  • roep de review-pro-skill direct aan.

De agent draait de hele pipeline native — git diff, leest gewijzigde bestanden, Globs .review-pro/ voor actieve stacks, stuurt de relevante reviewer-subagents erop af met hun stack-signalen, en synthetiseert één vonnis: BLOCK / REQUEST CHANGES / APPROVE. Geen env-vars, geen scripts om uit te voeren op review-tijdstip.

De 12 reviewers

security · correctness · craft · ai-antipatterns · dry · performance · backend · frontend · a11y · db · api-contract · tests. De ai-antipatterns-reviewer is first-class: gehallucineerde API's/symbolen/imports, verzonnen config/env-keys, overbodige afhankelijkheden en genegeerde bestaande helpers.

FAQ

Heeft het Node.js nodig?

Alleen de installer-CLI (Node ≥ 18). De plug-in zelf bestaat uit gewone markdown-skills en -agents, dus handmatige installatie werkt zonder Node op elk platform.

Waar verschilt dit van één enkele "beoordeel dit"-prompt?

Eén prompt overhandigt de hele diff aan één agent en vraagt alles. review-pro triageert eerst, draait alleen de relevante specialisten parallel met afgebakende context, en synthetiseert daarna — zodat kleine wijzigingen goedkoop blijven en grote diep gaan, met ern gekalibreerd tegen over-rapportage.

Waar komen de stack-pakketten vandaan?

De catalogus wordt meegeleverd in dit pakket, als momentopname bij publicatie. Nieuwe pakketten verschijnen nadat een nieuwe versie is gepubliceerd. Zie stacks/CONTRIBUTING.md in de repo om je eigen toe te voegen.

Is het echt platformoverstijgend?

Ja — één canonieke bron installeert in opencode, Claude Code, Cursor en Codex. Codex-agents worden automatisch naar TOML getransformeerd; de anderen consumeren dezelfde markdown-agents.
