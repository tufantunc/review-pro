Genel bakış

review-pro kademeli bir yapay zeka kod inceleme sistemidir: triyaj → ilgili uzman inceleyiciler → sentez. Yapay zeka ajanları tarafından yazılan kodu, yapay zeka ajanları kullanarak inceler — yapay zeka üretimi kodun gerçekte sahip olduğu hata biçimlerini yakalamak için tasarlandı: halüsinasyon API'lar, aşırı mühendislik, göz ardı edilmiş kurallar, gereksiz bağımlılıklar.

Bu CLI, review-pro çekirdeğini (12 inceleyici becerisi + alt ajanlar + review-pro orkestratörü) araç ajanına ve yığın paketlerini deponun .review-pro/ klasörüne kurar. Desteklenen hedefler: opencode · Claude Code · Cursor · Codex.

Kurulum

Tek seferlik. Etkileşimli — hangi platformların ve hangi yığın paketlerinin kurulacağını sorar.

npx review-pro init                           # interactive: pick platforms + stacks

Etkileşimsiz (CI)? --target <platform|all|auto> ve --no-stacks kullan.

Platform başına notlar

  • opencode — beceriler ~/.config/opencode/skills/'e, ajanlar ~/.config/opencode/agents/'e ($OPENCODE_HOME geçersiz kılar).
  • Claude Code — beceriler ~/.claude/skills/'e, ajanlar ~/.claude/agents/'e (ajanın skills: alanı rubriğini ön yükler).
  • Cursor — Cursor /add-plugin ile kurulur; Cursor'da /add-plugin https://github.com/tufantunc/review-pro çalıştır (depo bir .cursor-plugin/plugin.json içerir).
  • Codex — beceriler ~/.agents/skills/'e, ajanlar otomatik olarak ~/.codex/agents/*.toml'e dönüştürülür. Codex becerileri otomatik keşfeder; ajanlar oturumun beceri kümesini miras alır.

Sonra kullandığın yığın paketlerini ekle (aşağıda), yeni becerilerin/ajanların keşfedilmesi için aracını yeniden başlat ve bir inceleme çalıştır.

El ile kurulum (Node.js yok)

review-pro düz markdown beceri ve ajanlarıdır — çalışma zamanı bağımlılığı yoktur. Node.js'in yoksa (veya CLI'yı kullanmayı tercih etmiyorsan) dosyaları elle kopyala:

  1. Çekirdek — core/skills/<name>/ klasörünü aracının beceriler klasörüne ve core/agents/*.md dosyalarını ajanlar klasörüne kopyala (yukarıdaki platform başına yollar).
  2. Yığın paketleri — stacks/<pack>/ klasörünü incelenen deponun .review-pro/<pack>/ konumuna kopyala.
# example: opencode core + python stack, by hand
cp -R core/skills/*           ~/.config/opencode/skills/
cp    core/agents/*.md        ~/.config/opencode/agents/
mkdir -p .review-pro && cp -R stacks/python .review-pro/python

CLI yalnızca bu kopyaları otomatikleştirir (artı Codex .md→.toml dönüşümü ve sürüm takibi). El ile ve CLI kurulumları eşdeğerdir.

Yığın paketleri

Paketler, inceleme sırasında inceleyicilere dile/çerçeveye özgü sinyalleri katmanlar. Bir deponun kullandığı paketleri kendi .review-pro/ klasörüne kur. Çerçeve/alan paketleri bir dil paketinin üzerine eklenir.

npx review-pro                # interactive multi-select
npx review-pro add python     # one pack, CI-safe
npx review-pro list           # catalog + installed + drift

Katalog (14): python · go · rust · typescript-react · node · php · dotnet · kotlin · swift · flutter · nextjs · react-native · wordpress · ai-ml. Örnekler: bir Next.js deposu typescript-react + nextjs etkinleştirir; bir LLM uygulaması python + ai-ml etkinleştirir.

İnceleme çalıştır

Kurulum + yeniden başlatma sonrasında, incelemek istediğin depoda (bir özellik dalında):

  • oturumdan bu dalı review-pro ile incele iste, ya da
  • review-pro becerisini doğrudan çağır.

Ajan tüm boru hattını doğal olarak çalıştırır — git diff, değişen dosyaları okur, etkin yığınlar için .review-pro/ klasörünü tarar, ilgili inceleyici alt ajanları yığın sinyalleriyle görevlendirir ve tek bir karar sentezler: BLOCK / REQUEST CHANGES / APPROVE. İnceleme anında hiçbir ortam değişkeni, çalıştırılacak betik yoktur.

security · correctness · craft · ai-antipatterns · dry · performance · backend · frontend · a11y · db · api-contract · tests. ai-antipatterns inceleyicisi birinci sınıftır: halüsinasyon API'lar/semboller/importlar, uydurulmuş yapılandırma/ortam anahtarları, gereksiz bağımlılıklar ve göz ardı edilmiş mevcut yardımcılar.

SSS

Node.js gerektiriyor mu?

Yalnızca kurulum CLI'sı gerektirir (Node ≥ 18). Eklentinin kendisi düz markdown beceri ve ajanlarıdır, bu yüzden el ile kurulum herhangi bir platformda Node olmadan çalışır.

Tek bir “bunu incele” isteğinden farkı ne?

Tek bir istek tüm diff'i tek bir ajana verir ve her şeyi ister. review-pro önce triyaj yapar, yalnızca ilgili uzmanları kapsamlı bağlamla paralel çalıştırır, ardından sentezler — böylece küçük değişiklikler ucuz kalır, büyük değişiklikler derinleşir ve şiddet aşırı raporlamaya karşı kalibre edilir.

Yığın paketleri nereden gelir?

Katalog bu paketin içinde, yayımlama anında anlık görüntü olarak gelir. Yeni paketler yeni bir sürüm yayımlandıktan sonra görünür. Kendininkini eklemek için depodaki stacks/CONTRIBUTING.md dosyasına bak.

Gerçekten platformlar arası mı?

Evet — tek bir kanonik kaynak opencode, Claude Code, Cursor ve Codex'e kurulur. Codex ajanları otomatik olarak TOML'a dönüştürülür; diğerleri aynı markdown ajanları kullanır.

Aşamalar halinde düşünen kod incelemesi.
