# Stack pack: typescript-react — a11y
extends: core/skills/a11y/SKILL.md

## Stack-specific signals
- `<div onClick>` / `<span onClick>` for actions that should be a `<button>` or `<a>`.
- `<img>` (or CSS-background used as content) missing `alt`; decorative images that should use `alt=""` but instead have no attribute.
- Form controls without an associated `<label htmlFor>` or `aria-label`; placeholder used as a label.
- Icon-only buttons / link without `aria-label` or `aria-labelledby`.
- Modals/menus rendered via portals without focus trap or focus restore; `role="dialog"` + `aria-modal` missing.
- Lists without proper structure; or `aria-*` state (`aria-expanded`, `aria-selected`, `aria-hidden`) out of sync with component state.
- Visible focus styles removed (`outline: none`) with no replacement.

## Stack-specific remedies
- Use semantic elements; reach for ARIA only when no native element fits.
- Bind labels with `htmlFor`/`id`; give every interactive control an accessible name.
- Manage focus in portals/dialogs (trap on open, restore on close); wire ARIA state to real state.
- Never ship `outline: none` without an equivalent `:focus-visible` style.

## Stack-specific severity guidance
- Clickable non-semantic element with no role/name/keyboard support: High.
- ARIA state desynced from component state: Medium.
