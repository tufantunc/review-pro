review-pro 分阶段审查 AI 生成的代码。分流只分派相关的专家，每位在各自限定作用域的上下文中运行，随后综合返回单一裁定。专为 AI 代码实际存在的缺陷模式而构建。

01阶段

分流

对 diff 进行分类，只分派与本次改动相关的专家。每位拿到的是限定作用域的上下文——调用方、仓库检索、schema、消费者——而不是整个仓库。

分类界定分派
02阶段

分派

相关专家并行运行。十三位审查者，每人专注一项关注点，每人返回结构化、有据可查的发现，附带文件、行号、影响与补救措施。

并行受限结构化
03阶段

综合

对重叠项去重，按领域归属消解审查者间的冲突，针对过度上报校准严重性，并产出一个裁定——BLOCK、REQUEST CHANGES 或 APPROVE。

去重消解裁定

能力

一座审查工作台，而非一次笼统的猜测。

每位专家只负责一项关注点，并遵循严格的评审准则。一等公民的 AI 反模式视角能捕捉通用审查者遗漏的问题——虚构的 API、过度工程、被忽视的辅助函数、多余的依赖。

安装

一条命令。无锁定。

先将核心安装到你的工具，再添加你使用的技术栈包。

Claude Code —— 作为插件，无需 Node.js

/plugin marketplace add tufantunc/review-pro
/plugin install review-pro@review-pro

任意平台 —— 安装器 CLI

npx review-pro init            # interactive: pick platforms + stacks
npx review-pro add python      # add a stack to .review-pro/

没有 Node.js？review-pro 只是纯 markdown 技能与智能体——把它们复制到你的工具的目录中，效果完全一样。参见手动安装指南。

然后重启你的工具并运行一次审查——开一个分支并让会话审查它，或调用 review-pro 技能。
