# Stack pack: react-native — a11y
extends: core/skills/a11y/SKILL.md

## Stack-specific signals
- `TouchableOpacity`/`Pressable`/`TouchableWithoutFeedback` without `accessibilityLabel`/`accessibilityRole` → unlabeled controls on VoiceOver/TalkBack.
- `Image` without `accessible` + `accessibilityLabel` (or empty) for informative images; decorative images not marked `accessibilityElementsHidden`.
- `accessibilityState` (checked/selected/expanded) not bound to real component state.
- Missing focus/order for custom lists; `FlatList` items without stable `key`/`accessibilityHint`; tap targets below ~44pt.
- Contrast introduced in the diff below WCAG AA; hiding whole views with `opacity: 0` instead of `accessibilityElementsHidden`/`display:none`.

## Stack-specific remedies
- Give every interactive element a role + label; bind `accessibilityState` to state; add hints; keep ≥44pt targets; AA contrast.

## Stack-specific severity guidance
- Unlabeled/unfocusable interactive control: High.
- `accessibilityState` desynced from state / contrast regression: Medium.
